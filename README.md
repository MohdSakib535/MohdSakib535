## 📌 Featured Projects

### 🧠 [SkillProof-AI](https://github.com/MohdSakib535/SkillProof-AI)
Event-driven, **multi-agent** resume/JD fit analyzer that scores candidate fit and generates an adaptive skill-verification quiz. Architected as **8 containerized services** with a **4-node LangGraph pipeline** (extractor → matcher → quiz generator → evaluator), Postgres-backed interrupt/resume checkpoints, async **FastAPI + Celery + Redis** jobs, dual persistence (PostgreSQL + MongoDB), and a **Kafka + Debezium CDC** pipeline streaming into **Elasticsearch**.

`Python` · `FastAPI` · `LangGraph` · `Celery` · `Kafka` · `Debezium` · `Elasticsearch` · `Docker`

### 🔎 [rag-fastApi-project](https://github.com/MohdSakib535/rag-fastApi-project)
Production-grade **RAG Q&A** over PDF, DOCX, TXT, and YouTube transcripts. Chunking + embeddings in **ChromaDB**, **LangChain** cosine-similarity retrieval for source-grounded answers, prompt-injection hardening, and a decoupled **FastAPI + Streamlit** architecture with Swagger/ReDoc docs.

`FastAPI` · `LangChain` · `LlamaIndex` · `ChromaDB` · `Streamlit` · `Docker`

### 🧹 [data-quality-agent](https://github.com/MohdSakib535/data-quality-agent)
FastAPI-based **CSV quality analysis and AI cleaning engine** with data-quality scoring, issue prioritization, and structured cleaning workflows.

`FastAPI` · `Python` · `LLM`

### 💬 [csv-query-engine](https://github.com/MohdSakib535/csv-query-engine)
Upload a CSV and ask questions in plain English — safely translated into **DuckDB SQL** (optionally via OpenAI) with results returned through a clean API.

`FastAPI` · `DuckDB` · `OpenAI`

### 🎥 [FastApi_WebRTC](https://github.com/MohdSakib535/FastApi_WebRTC)
Real-time **WebRTC** video rooms with browser speech-to-text streamed to Postgres, plus AI-generated downloadable **PDF summaries** via REST endpoints.
